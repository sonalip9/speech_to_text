# speech_to_text

A learning project: build a speech-to-text system from scratch to understand how it works.

- Language: English only
- Stack: Python, PyTorch, torchaudio, NumPy, `uv`; FastAPI for serving later
- Data: LibriSpeech
- Compute: free only (Apple GPU locally, Colab/Kaggle for longer runs)
- Approach: CTC model first, then study attention-based models (Whisper)

See [docs/PLAN.md](docs/PLAN.md) for the learning and coding plan.
